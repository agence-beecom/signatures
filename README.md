# Signatures e-mail — Groupe Beecom'

Images hébergées pour les signatures e-mail HTML (ASP Édition, Beecom').
Servies par GitHub Pages : `https://agence-beecom.github.io/signatures/<marque>/<personne>/<fichier>`

Ne pas renommer ni supprimer de fichier : les signatures déjà installées pointent dessus.
Pour modifier une image, la remplacer en gardant exactement le même nom.

- `asp-edition/benoit-bernardin/v5/` — V5 480 px (fond en images)
- `asp-edition/benoit-bernardin/v6/` — V6 480 px, dégradé CSS sur un seul bloc (version installée)
